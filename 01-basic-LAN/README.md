
# Lab 1 - Basic LAN

## Hedef

Cisco Packet Tracer kullanarak temel LAN kurma ve 
aynı ağdaki cihazlar arasındaki temel iletişimi anlama.

## Topoloji

PC1 ─── Switch ─── PC2

## IP Addresleme

| Device | IP Address    | Subnet Mask |
|---|---|---|
| PC1    | 192.168.10.10 | 255.255.255.0 |
| PC2    | 192.168.10.20 | 255.255.255.0 |

## Testler

### Ping Testi

PC1 → PC2

Sonuç: Başarılı

### Ne Öğrendik?

- Temel LAN topolojisi
- IPv4 addresleme
- Subnet maskler
- Ping ile temel bağlantı testi
- Switch'in LAN'daki görevi
